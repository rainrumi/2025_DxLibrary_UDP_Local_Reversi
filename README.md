# 2026\_DxLibrary\_UDP\_Local\_Reversi

UDP通信を利用したDxライブラリ製のオセロゲーム

\## 概要

UDP通信を利用したオセロゲーム。

制作期間は2025年9月～1月あたり

UnityでMirrorを使ったことがあったので、そこで得たネット周りの仕様に寄せて作っています。



\## 接続できない場合

接続後に進行しない場合IP間違えています



\## 接続方法

・２台のPCで起動、または１台のPCでプロジェクトを２つ実行します

・画面の指示に従って起動します

・クライアント側ではホストのほうに書かれたIPアドレスを入力します

・接続完了
